#  Given a list of integers that includes negative numbers, use filter() to remove all negatives, then use map() to square the remaining values. Chain the two operations so no intermediate named variable is required.

numbers = [-3, -1, 0, 2, 4, -2, 5, 7]

result = list(
    map(lambda n: n ** 2,
        filter(lambda n: n >= 0, numbers))
)

print(result)
